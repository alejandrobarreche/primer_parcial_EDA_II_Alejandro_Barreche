# Town graph — shortest paths and connectivity

First midterm of *Estructuras de Datos y Algoritmos II* (UAX, November 2024). A weighted graph of towns around Madrid with a console menu to compute the shortest route (Dijkstra), check connectivity with DFS, list towns with short connections, enumerate alternative cycle-free routes, draw the graph with networkx and benchmark each operation.

## Run

```bash
pip install networkx matplotlib
python main.py
```

`rutas.py` holds the `Graph` class; `main.py` is the interactive menu.
